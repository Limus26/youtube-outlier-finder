# YouTube Outlier Finder

키워드로 유튜브 영상을 검색해서, **구독자 수는 적은데 조회수는 높은** 영상(=숨은 떡상 영상)을
점수 기준으로 정렬해 보여주는 개인용 도구입니다. 뷰트랩(viewtrap.com)의 '영상검색' 기능을
참고해서 만들었으며, 로그인/결제 없이 혼자 쓰는 용도로 설계했습니다.

브라우저에서 검색어를 입력하고 버튼만 누르면 되는 **웹 화면**과, 터미널 명령어로 쓰는 **CLI**
두 가지 방식을 모두 지원합니다. 터미널이 익숙하지 않다면 웹 화면 사용을 추천합니다.

## 빠른 시작 (로컬 웹 화면, 이 맥북에서만)

최초 1회만 아래 "설치" 섹션대로 준비를 마치면, 그다음부터는 이 폴더 안의
**`실행하기.command`** 파일을 더블클릭하기만 하면 됩니다.

1. 더블클릭하면 터미널 창이 하나 뜨고, 잠시 후 브라우저가 자동으로 열립니다.
2. 왼쪽 사이드바에 YouTube API 키를 입력합니다. ("이 컴퓨터에 키 저장하기"를 체크하면 다음부터
   다시 입력할 필요가 없습니다.)
3. 가운데 검색창에 원하는 키워드를 입력하고 **검색** 버튼을 누릅니다.
4. 영상 썸네일이 포함된 표로 결과가 나오고, **CSV로 저장** 버튼도 누를 수 있습니다.

화면 위쪽에는 "오늘 남은 예상 유닛" 배지가 항상 작게 표시됩니다. 이 프로그램으로 검색할 때마다
소모한 유닛을 로컬 파일(`quota_usage.json`)에 누적 기록해서 보여주는 것이라, 이 API 키를 다른
프로그램에서도 같이 쓴다면 실제 구글 콘솔 수치와는 다를 수 있는 **추정치**입니다. 태평양시간
자정에 자동으로 0부터 다시 셉니다.

프로그램을 끄고 싶으면, 열려 있는 터미널 창을 닫으면 됩니다 (또는 그 창에서 Control+C).

> macOS가 "확인되지 않은 개발자" 경고를 띄우면, `실행하기.command`를 마우스 오른쪽 버튼으로
> 클릭 → **열기**를 선택하면 한 번만 더 확인하고 실행됩니다.

**보안 참고**: `실행하기.command`는 `--server.address localhost` 옵션으로 실행되어, 이 컴퓨터
밖(같은 와이파이의 다른 기기 포함)에서는 접근할 수 없습니다. 카페 같은 공용 와이파이에서 써도
안전합니다.

## 핵심 로직

- **점수 = 조회수 ÷ 구독자수** (`--score-mode simple`, 기본값)
- **점수 = (조회수 ÷ 구독자수) ÷ 게시 후 경과일수** (`--score-mode recency`) — 최근 영상에 가중치
- 구독자 수를 비공개로 설정한 채널은 점수를 계산할 수 없으므로 표에는 `N/A`로 표시하고,
  순위(`순위` 열)는 매기지 않습니다. (표에서 아예 빠지지는 않습니다 — 어떤 영상인지는 볼 수 있게 유지)

## 준비물

- Python 3.9 이상
- YouTube Data API v3 키

### API 키 발급 방법 (Google Cloud Console)

1. [Google Cloud Console](https://console.cloud.google.com/)에 접속해 새 프로젝트를 만듭니다 (또는 기존 프로젝트 사용).
2. 좌측 메뉴 **APIs & Services > Library**로 이동해 `YouTube Data API v3`를 검색 후 **Enable**.
3. **APIs & Services > Credentials**로 이동해 **Create Credentials > API key**를 클릭.
4. 발급된 키를 복사합니다. (선택) 키를 클릭해 **Application restrictions**를 설정하면 더 안전합니다.
5. 무료 할당량은 **일일 10,000 유닛**이며 태평양시간(PT) 자정에 리셋됩니다. 셀프서비스로 늘릴 수 있는
   방법은 없습니다.

## CLI 사용법

```bash
python youtube_outlier.py "키워드"
```

### 옵션

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `keyword` | 검색 키워드 (필수, 위치 인자) | - |
| `--api-key` | YouTube API 키. 미지정 시 `YOUTUBE_API_KEY` 환경변수 사용 | - |
| `--order` | search.list 조회 순서: `viewCount` / `date` / `relevance` | `viewCount` |
| `--sort-by` | 결과 표 정렬 기준: `score` / `views` / `date` | `score` |
| `--max-results` | 검색할 최대 영상 수 (최대 500) | `150` |
| `--days` | 최근 N일 이내 게시된 영상만 검색 | 제한 없음 |
| `--min-views` | 최소 조회수 필터 | `0` |
| `--min-subscribers` | 최소 구독자 수 필터. 구독자가 극소수인 채널(통계적 노이즈)을 걸러낼 때 사용. 구독자 비공개 채널도 함께 제외됨 | `0` |
| `--score-mode` | `simple` (조회수/구독자) 또는 `recency` (경과일수로 나눔) | `simple` |
| `--csv` | 결과를 저장할 CSV 경로 | 저장 안 함 |

> `--order`는 YouTube에 "어떤 영상 후보를 가져올지"를 정하는 옵션이고, `--sort-by`는
> "가져온 결과를 화면에 어떤 기준으로 보여줄지"를 정하는 옵션입니다. 두 값은 독립적입니다.
> 예를 들어 `--order viewCount`로 조회수 상위 후보를 모은 뒤 `--sort-by score`로 그 안에서
> 점수가 높은 순으로 다시 정렬해 보여주는 것이 기본 동작입니다.

### 실행 예시

```bash
# 기본: "브이로그" 키워드로 검색, 점수순 정렬
python youtube_outlier.py "브이로그"

# 최근 7일 이내 게시 + 최소 조회수 1만 + 최근 가중치 점수
python youtube_outlier.py "부업" --days 7 --min-views 10000 --score-mode recency

# 검색은 최신순으로 가져오되, 화면은 조회수순으로 보고 CSV로 저장
python youtube_outlier.py "재테크" --order date --sort-by views --csv result.csv

# API 키를 옵션으로 직접 전달
python youtube_outlier.py "요리" --api-key YOUR_KEY --max-results 300
```

## 테스트 방법

1. API 키를 발급받아 환경변수로 등록합니다.
2. 유닛 소모가 적은 값으로 먼저 시도해보세요 (예: `--max-results 50` → search.list 100유닛만 소모).

   ```bash
   python youtube_outlier.py "테스트" --max-results 50
   ```
3. 정상 동작 시 표와 하단의 API 사용량 요약이 출력됩니다. 실행할 때마다 유닛이 얼마나
   쌓이는지 확인하면서 `--max-results`를 조정하세요.
4. 옵션 조합별로 결과가 바뀌는지 확인합니다.
   - `--days 30` 등을 넣었을 때 최근 게시물만 나오는지
   - `--min-views` 이하 영상이 빠지는지
   - `--score-mode recency`로 바꿨을 때 최근 영상 점수가 상대적으로 올라가는지
   - `--csv` 지정 시 파일이 실제로 생성되는지
5. API 키 오류(`--api-key` 잘못 입력) 시 에러 메시지가 잘 뜨는지도 확인해보면 좋습니다.

## 유닛 소모 가이드

- `search.list` 호출 1번 = 100유닛, 페이지당 최대 50개 결과, 한 검색어당 최대 약 500개까지만 접근 가능
- `videos.list` / `channels.list`는 50개씩 묶어도 호출당 1유닛 — 상세정보 조회 비용은 무시할 수준
- `--max-results 150`(기본값) 기준 대략 `300 + a` 유닛 소모 → 하루 10,000유닛 한도 내에서
  약 30회 정도 기본 설정으로 검색 가능
- `--max-results`를 500까지 올리면 search.list만 1,000유닛 소모되니 신중하게 사용하세요

## 1차 범위에서 의도적으로 제외한 것 (다음 단계 논의용)

- **성장속도 (구독자 증가 추이)**: 하루 단위로 구독자 수를 누적 기록해야 계산 가능한 시계열
  지표라 이번 범위에서는 뺐습니다. 다음 단계에서 로컬 SQLite 등에 일별 스냅샷을 쌓는 방식을
  고려할 수 있습니다.
- **노출확률**: 유튜브가 공식적으로 공개하지 않는 값이라, 조회수 증가 속도 · 채널 평균 대비
  배수 · 참여율(좋아요/댓글 비율) 등으로 근사해야 하는데 아직 근사 모델을 설계하지 않았습니다.
- **채널트렌드 / 채널분석**: 이번 범위(영상 검색)에 집중하기 위해 다음 단계로 미뤘습니다.

## 다음 단계 제안

1. **일별 스냅샷 저장 → 성장속도 지표**: cron이나 launchd로 하루 1회 관심 채널의 구독자/조회수를
   SQLite에 적재하고, 최근 N일 기울기로 "성장속도" 근사치를 계산.
2. **노출확률 근사 모델 설계**: 채널 평균 조회수 대비 배수(예: 이 영상 조회수 / 최근 10개 영상
   평균 조회수)와 좋아요·댓글 참여율을 조합한 자체 지표 초안을 잡고, 뷰트랩 등급과 상관관계를
   눈으로 검증.
3. **채널분석 기능**: 특정 채널 하나를 넣으면 최근 영상들의 점수 분포, 업로드 주기, 평균 조회수
   추이를 보여주는 서브커맨드 추가.
4. **결과 캐싱**: 같은 키워드를 반복 조회할 때 search.list 100유닛을 매번 쓰지 않도록, 최근 조회
   결과를 로컬에 짧은 TTL로 캐싱.
5. ~~간단한 로컬 웹 UI~~ → 완료 (`app.py` / `실행하기.command`). 다음은 여기에 검색 기록 저장,
   즐겨찾기 키워드 같은 편의 기능을 얹는 것을 고려할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `실행하기.command` | 더블클릭으로 웹 화면을 켜는 실행 파일 (macOS) |
